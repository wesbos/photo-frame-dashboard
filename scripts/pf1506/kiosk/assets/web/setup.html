Frame settings

This page is served by the photo frame on your home network.

Calendars

For each Google Calendar, on a computer: Settings → the calendar → Integrate calendar → Secret address in iCal format. Anyone with that address can read the calendar, so share it only here. Other services' iCal (.ics) addresses work too.

Weather

Chores (optional)

Make a separate calendar for chores and paste its secret iCal address. Title each event with who it's for: Ana: Make bed, Ana, Ben: Feed the dog, or no name for everyone. A chore that repeats weekly stays on the list all week.
